# 管理画面の文言表と、実機でしか確かめられない項目(#150)

[`management-window.html`](management-window.html) の対になる表。HTML は**スクリーンショットではなくモック**で、
WPF の実物ではない(WSL で WPF を起動できないため、見た目と文言をブラウザで先に詰める。requirements §10.3)。

- 文言の ID(`W-###`)は HTML の `data-w` 属性と一致させている。直すときは両方を直す
  (`python3` で両者の ID の集合が一致するか確かめている。PR #161 の本文を参照)。
- 「根拠」の列:
  - `ファイル:行` … **いまのコードにある文言**(トレイ・ダイアログ・トースト)。そのまま使うか、場所だけ画面の中に移す
  - `§10.3` / `ADR-0017` / `ADR-0018` / `CONTEXT.md` / `#5 Q10` … 設計の docs・issue に書かれた語
  - **案** … 根拠が無く、このモックで決めた文言。**人が見て了承するまでは確定ではない**
- 行番号は main の `243358e` 時点。`{…}` は差し込む値。

- [ ] **フォントと DPI**:WPF 既定のフォント(Yu Gothic UI / Meiryo UI)と既定の文字の大きさで、日本語の番組名が読めるか。

- [ ] **要対応の長い番組名・フォルダ名**:折り返すか省略するか。省略したとき全文を見る手段(ツールチップ)があるか
- [ ] **トレイの既定の項目**:`Radirec を開く` が太字になるか。アイコンのダブルクリックで開くか(シングルクリックでメニューが出るかも)
