# 番組 identity は録音元フォルダを拠り所にする

Status: accepted(M1 の設計判断 D11「Class A/B はファイル名を番組名の権威にする」を改訂・置換)

らじれこはファイル名の頭に週替わりゲスト名や特番副題を入れるため、ファイル名由来の番組名は
同じ番組でも回ごとに変わる(実データで `オールナイトニッポン0(ZERO)` フォルダが 43 個の別アルバムに
分裂、全6局で17番組が分裂)。一方で**フォルダは番組ごとに安定**しており、ゲストは各回の埋め込み
`artist` タグに確実に入っている。よって **番組の同一性(グルーピング=アルバム、および同一性キーの
番組成分)はフォルダ名を拠り所にする**。ファイル名からは放送局・録音種別・放送日時のみを採り、
番組名の識別には使わない。ゲストは放送回の `artist` として保持する。

## Considered Options

- **(A) フォルダ名を既定の identity にする(採用)** — 週替わりゲストも表記ゆれ(空白違い等)も
  config なしで 1 アルバムに収束する。ANN0 はフォルダ名がそのまま良い名前なので設定不要。
- (B) ファイル名を既定のまま、`programs.json` にフォルダ・マッチを opt-in で足す — 表示名は
  綺麗だが、分裂する 17 番組(と今後のゲスト番組)を都度明示登録する必要がある。
- (C) 「ファイル名がフォルダと一致すれば綺麗名、違えばフォルダ名」ヒューリスティック — config は
  ほぼ不要だが、正規化は同じでも文字列が違うケース(`SONY SONPO`⇔`SONYSONPO`)で Jellyfin 上
  2 アルバムになり表記ゆれを直せない。

## Consequences

- ラテン番組はフォルダ名が空白除去形(例 `LOGISTEEDRADIONOMICS`)で表示される。綺麗な表示名に
  したい場合は `programs.json` の `Canonical.Album` で整形する(任意)。
- 同一性キーの番組成分がフォルダ由来になる(ファイル名由来から変更)。M1 時点では実運用データが
  無いため移行は不要。
- 1 番組が複数フォルダに分かれているケース(例 `…ふらっと(1)`/`(2)`)は、`programs.json` の
  `Folders`(複数)→ 1 `Album` で手動統合する。
